## 1. Introduction

("we", "us", "our") operates the Sitecore Marketplace Jira Task View application ("the App"), a Jira integration that provides task management and work breakdown capabilities within the Sitecore Marketplace ecosystem.

This Privacy Policy describes how we collect, use, store, and protect your information when you use the App.

## 3. How We Use Your Data

We use your data exclusively for:

1. **Jira Integration** — Reading and writing Jira issues, projects, and comments on your behalf
2. **Session Management** — Maintaining your authenticated session
3. **AI Task Breakdown** (optional) — Generating work breakdowns from your requirement descriptions
4. **Security & Auditing** — Logging connection events and token refreshes for security monitoring
5. **Real-time Updates** — Synchronizing the UI when Jira issues change via webhooks

We do **not** use your data for:

- Advertising or marketing profiling
- Selling to third parties
- Training AI models (OpenAI API data is not used for training by default)
- Analytics or behavioral tracking

## 5. Data Storage & Security

### 5.1 Encryption at Rest

- **Jira OAuth tokens** are encrypted using **AES-256-GCM** at the application layer before storage in the database. Plaintext tokens never exist in the database.
- **Database storage** is encrypted at rest using **AES-256** (AWS-managed encryption on Supabase infrastructure).
- **Backups** are encrypted at rest using the same AWS-managed encryption.

For full technical details, see the [Encryption at Rest](./encryption-at-rest.md) document.

### 5.2 Encryption in Transit

- All browser-to-server communication uses **HTTPS (TLS 1.2+)**
- All server-to-database connections use **TLS** (`sslmode=require`)
- All server-to-Jira API connections use **HTTPS**
- Session cookies are set with `secure: true` (HTTPS-only), `httpOnly: true` (no JavaScript access), and `sameSite: "none"`

### 5.3 Access Controls

- The Supabase service role key is stored as an environment variable and is never exposed to the browser
- The browser Supabase client uses the anon key with limited permissions
- Row Level Security (RLS) is enabled on the `jira_webhook_events` table
- Session tokens are 256-bit cryptographically random values

## 7. Your Rights & How to Exercise Them

If you are in the European Economic Area (EEA), United Kingdom, or other jurisdictions with data protection laws, you have the following rights:

| Right                | How to Exercise                                                                                                                                                                                                       |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Erasure**          | Click **Disconnect** in the App UI to deactivate your connection and delete your session. You can also revoke the App's access entirely via [Atlassian Connected Apps](https://id.atlassian.com/manage-profile/apps). |
| **Withdraw Consent** | Stop using the AI feature at any time — no AI data is persisted. Disconnect to revoke all Jira access consent.                                                                                                        |

**Note:** The App does not collect email addresses, names, or other contact information. It only stores your Jira `accountId` (a pseudonymous identifier from Atlassian). Data subject requests should be routed through the Sitecore Marketplace support channel or your organization's Jira administrator.

For the technical procedures used to fulfill data subject requests, see the [DSAR Workflow](./dsar-workflow.md) document.
